# BLACK / WHITE  
### Brutalist × Luxury Editorial Landing Page

BLACK / WHITE is a design-focused landing page built using **only HTML and CSS**.  
It explores the intersection of **brutalism**, **luxury editorial design**, and **Swiss grid principles** — without relying on color, JavaScript, or external libraries.

This project is intentionally minimal, confident, and slightly uncomfortable.

---

## ✨ Concept

The goal of this project is not decoration, but **declaration**.

- Brutalist structure (visible grids, heavy rules)
- Luxury restraint (silence, spacing, typography)
- Editorial pacing inspired by fashion magazines
- Pure black & white — no grayscale tricks, no color accents

Every design decision is deliberate.

---

## 🧱 Design Principles

- **Typography-first layout**
- **Extreme hierarchy** (scale, spacing, contrast)
- **Intentional misalignment** to avoid template perfection
- **Subtractive design process**
- **Silence as a design element**

This is not a UI kit.  
This is an editorial statement.

---

## 🧭 Structure

The landing page is divided into three conceptual sections:

- **Design** — visual system, hierarchy, restraint
- **Process** — subtractive approach to creation
- **Philosophy** — brutalism as honesty, luxury as control

Navigation is implemented using **CSS-only tabs**.

---

## ⚙️ Technical Details

- **HTML5**
- **CSS3**
- No JavaScript
- No frameworks
- No external fonts or assets
- Fully responsive
- CSS-only interactions and transitions

---

## 🎯 Challenge Constraints

This project was created to satisfy the following constraints:

- Use **only black and white**
- Demonstrate strong visual balance
- Maintain consistent style throughout
- Enhance usability without relying on color
- Avoid JavaScript entirely

---

## 🖨️ Usage

1. Clone or download the repository
2. Open `index.html` in any modern browser
3. No build steps required
